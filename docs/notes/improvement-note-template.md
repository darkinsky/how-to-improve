# 改进笔记模板

## 基本信息

- **主题：**
- **日期：**
- **领域：** 工程 / 科研 / 习惯 / 其他
- **状态：** 计划中 / 进行中 / 已验证 / 已放弃

## 1. 想改进什么？

描述具体问题，避免只写抽象目标。

## 2. 当前状态是什么？

尽量用事实、数据或具体案例描述现状。

## 3. 改进假设

如果我做了什么，那么什么指标或体验会变好？

## 4. 行动计划

- [ ] 行动 1
- [ ] 行动 2
- [ ] 行动 3

## 5. 判断标准

如何判断这次尝试是否有效？

## 6. 实际结果

记录执行后的真实情况。

## 7. 复盘

- 有效的是什么？
- 无效的是什么？
- 下次怎么调整？

## 8. 可沉淀内容

可以沉淀成原则、模板、脚本或流程的内容。
