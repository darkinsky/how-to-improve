## 先看结论

公开课自学最容易犯的错误是“收藏太多、完成太少”。这份清单的使用方式不是全学，而是按目标选择一条主线，并把关键课程的作业 / Lab 做完。

优先级判断：

| 优先级 | 含义 | 典型课程 |
|--------|------|----------|
| P0 | CS 能力底座，长期收益最高 | CS61A / CS61B / CSAPP / 6.S081 / 15-445 / 6.5840 |
| P1 | 按方向强烈推荐 | CS336 / CS149 / CS144 / CS224n / CS231n / CS285 |
| P2 | 有明确兴趣或职业方向再学 | 编译器、安全、密码学、Web 工程等专题课 |

学习建议：

```text
先完成 1 门编程基础 + 1 门数据结构
再进入系统 / 算法 / 数据库 / 网络
最后按目标选择 AI / Infra / 安全 / 编译器 / 分布式专题
```

## 课程分层地图

| 层级 | 目标 | 必读课程 | 完成标准 |
|------|------|----------|----------|
| L0 入门 | 会写程序，理解抽象 | CS50x / CS61A / CS106A | 能独立完成小项目，理解递归、抽象、测试 |
| L1 数据结构与算法 | 能组织程序和分析复杂度 | CS61B / MIT 6.006 / Princeton Algorithms | 能实现树、图、哈希、DP，并分析复杂度 |
| L2 系统基础 | 理解程序如何运行 | CSAPP / MIT 6.S081 / CS162 | 能解释内存、链接、系统调用、并发和文件系统 |
| L3 数据与网络 | 理解后端基础设施 | CMU 15-445 / CS186 / CS144 / 15-441 | 能实现小型 DB / TCP / KV store 组件 |
| L4 分布式与性能 | 理解大规模系统 | MIT 6.5840 / CS149 / CS267 | 能实现 Raft / MapReduce，做性能 profiling |
| L5 AI / ML 专题 | 进入现代 AI 系统 | CS229 / CS224n / CS231n / CS336 / DLSys | 能训练、评测和分析模型系统 |

## 如果只学 8 门核心课

如果时间有限，建议不要平均用力，优先完成下面 8 门：

1. **CS61A 或 CS50x** — 编程抽象 / CS 入门；
2. **CS61B** — 数据结构和工程化编程；
3. **MIT 6.006** — 算法基础；
4. **CSAPP / CMU 15-213** — 计算机系统；
5. **MIT 6.S081 / Berkeley CS162** — 操作系统；
6. **CMU 15-445 / Berkeley CS186** — 数据库系统；
7. **MIT 6.5840** — 分布式系统；
8. **CS336 或 CS149** — 根据目标选择 LLM 或并行计算。

---

## 选课避坑

- 不要同时开太多硬课：CSAPP、6.S081、15-445、6.5840 都是高强度课程。
- 视频不是完成标准：至少完成核心作业、Lab 或项目。
- 算法课不要只刷视频：必须写代码和做题。
- 系统课不要跳 Lab：系统能力主要来自 debug、profiling 和实现。
- AI 方向不要绕过系统基础：训练、推理和部署都依赖 OS、网络、并行计算和数据库基础。
- 课程年份不必追最新：经典课优先选资料完整、作业可访问的一期。
