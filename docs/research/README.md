# Research

记录科研相关的改进：论文阅读、问题定义、实验设计、结果分析、学术写作、研究节奏管理等。

---

## 先看结论

Research 目录的目标是把研究活动变成可复盘流程：

```text
问题定义 → 文献地图 → 假设 → 实验设计 → 结果分析 → 写作与复盘
```

研究笔记不只摘录论文结论，更要沉淀：为什么重要、假设是什么、证据够不够、下一步怎么验证。
