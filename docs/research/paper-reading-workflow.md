# Paper Reading Workflow

## 先看结论

读论文不要只摘摘要，而要拆成四件事：问题、方法、证据、局限。

```text
Skim → Structure → Deep Read → Reproduce / Compare → Note
```

目标是判断这篇论文是否改变了你的研究地图，而不是记住所有细节。

---

## 三遍阅读法

1. **第一遍：定位**
   - 研究问题是什么？
   - 结论是否和当前方向相关？
   - 是否值得精读？
2. **第二遍：结构化**
   - 方法核心假设是什么？
   - 与 baseline 的差异在哪里？
   - 实验如何支撑结论？
3. **第三遍：批判性阅读**
   - 消融是否充分？
   - 数据和评估是否可信？
   - 可能的失败场景是什么？
   - 是否能复现或迁移？

---

## 论文卡片模板

```markdown
# Paper Card

## Citation
## Problem
## Core Idea
## Method
## Evidence
## Limitations
## Relation to My Work
## Reproduction Notes
## Follow-up Papers
```

---

## 读完后的完成标准

- 能用 3 句话解释论文贡献；
- 能画出方法流程图；
- 能指出至少 2 个局限；
- 能列出与自己项目相关的下一步实验或对照。
